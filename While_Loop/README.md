# While Loop — Logic Building

This section contains Java problems designed to develop a strong understanding of the `while` loop and improve programming logic.

The problems gradually move from basic iteration to number manipulation and digit-based problems.

---

## What I am Learning

Through these problems, I am practicing:

* `while` loop
* Loop initialization
* Loop condition
* Loop update
* Counter-based problems
* Digit extraction
* Number manipulation
* Mathematical operations
* Dry running loops
* Breaking a problem into logical steps

# Important Reminder

The purpose of these problems is not to memorize code.

The goal is to develop the ability to answer:

> **"What should happen at every iteration of the loop?"**

Before writing code, I should be able to explain the logic on paper.
